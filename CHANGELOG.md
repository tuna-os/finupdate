# Changelog

All notable Finupdate releases are documented here.

## [0.1.0] - 2026-10-20

The first tagged Finupdate release.

### Highlights

- GTK4/libadwaita system update frontend for `bootc`, Flatpak, brew, and
  distrobox updates.
- Registry history for Bluefin, Aurora, Bazzite, and Dakota image streams,
  including dated-tag and SHA-tag probing.
- Host-image detection through `bootc status` with an `/etc/os-release`
  fallback for Flatpak environments.
- Release artifacts for x86_64 and aarch64, with versioned OCI tags and
  architecture-specific Flatpak bundles.
